1. Install AppLovin Installer package from official website: https://support.axon.ai/en/max/unity/overview/integration

2. Follow instructions on initial AppLovin package setup.

3. Add this package in `Unity Package Manager` using the following URL:

```
https://github.com/MirraSDK/SDK5-AppLovin-API.git
```

4. In MirraSDK Toolkit, select the AppLovinAds provider and set the Android or iOS ad unit IDs for interstitial, rewarded, and banner ads.
